🤖 AI-Assisted Cybersecurity Lab with Kali Linux

Project Overview

I completed a hands-on project integrating an AI command-line assistant into my Kali Linux virtual machine.

The objective was to explore how AI can help generate and explain network reconnaissance commands while strengthening my practical skills in Linux administration, virtualization, authentication, and cybersecurity tools.

Objectives

* Deploy Kali Linux in VMware Workstation.
* Install and configure an AI command-line assistant.
* Complete account authentication.
* Explore AI-assisted Nmap command generation.
* Troubleshoot CLI configuration issues.

Tools and Technologies

* VMware Workstation
* Kali Linux 2026.2
* Amazon Q Developer / Kiro CLI
* AWS Builder ID authentication
* Nmap

Note: Verify the exact CLI product and version before publishing. Amazon Q Developer and Kiro CLI are distinct products.

Implementation

1. Virtual Machine Setup

Deployed Kali Linux in VMware Workstation to create a dedicated cybersecurity learning environment.

2. CLI Installation

Installed and configured the AI command-line assistant in the Kali Linux terminal.

3. Authentication

Used the OAuth device-flow process to authenticate the CLI.

4. Troubleshooting

Encountered an authentication command that did not work with the installed version. Investigated the error and corrected the command syntax using the relevant documentation.

5. Nmap Testing

Tested the assistant’s ability to generate and explain commands for host discovery and service detection.

All scanning must be restricted to systems I own or have explicit permission to test.

Key Learning Outcomes

* Linux administration
* Virtualization
* CLI installation and troubleshooting
* Authentication workflows
* AI-assisted command generation
* Network reconnaissance fundamentals

Security Considerations

* Review AI-generated commands before executing them.
* Scan only authorized systems.
* Protect credentials, tokens, and private keys.
* Avoid exposing sensitive information in screenshots or documentation.

Future Improvements

* Document the lab architecture.
* Test the workflow in a controlled lab environment.
* Develop a repeatable reconnaissance workflow.
* Explore vulnerability reporting.
* Investigate how AI-assisted security workflows can complement cloud security monitoring.

Conclusion

This project helped me explore AI-assisted cybersecurity while developing practical experience with Linux, virtualization, authentication, and network reconnaissance.

I’m continuing to build hands-on projects as I develop my cybersecurity and cloud security skills.
